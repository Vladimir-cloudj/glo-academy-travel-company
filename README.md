# Путешествия по России

SPA-приложение для просмотра каталога туров по России, реализованное на Vue.js.  
Проект создан в рамках учебного курса по Vue.js.

## Реализованный функционал

- **Каталог туров** — отображение списка из 6 туров с картинками, заголовками и краткими описаниями
- **Страница отдельного тура** — детальный просмотр информации о выбранном туре
- **Динамический роутинг** — переходы между страницами без перезагрузки (SPA)
- **Хранение данных в Vuex** — единый источник данных для всего приложения
- **Переиспользуемые компоненты** — `TourCard` используется для всех карточек
- **Обработка ошибок** — корректное отображение страницы "Тур не найден" при неверном ID
- **Фильтрация текста** — автоматическая обрезка описаний туров до 400 символов с добавлением текста "Читать далее..."

## Архитектурные принципы

- **Single Source of Truth** — все данные о турах хранятся в Vuex-модуле `tours.js`
- **DRY (Don't Repeat Yourself)** — компонент `TourCard` используется многократно
- **Модульность** — данные разделены на отдельные Vuex-модули
- **Component-based подход** — UI разбит на переиспользуемые компоненты
- **Data-driven рендеринг** — списки отрисовываются через `v-for`

## Как это работает

1. При загрузке приложения Vuex-модуль tours.js инициализирует массив из 6 туров с уникальными UUID.
2. ToursView получает список через геттер getAllTours и отрисовывает его через v-for.
3. При клике на карточку TourCard срабатывает router-link с объектной записью маршрута.
4. TourSingleView получает ID из URL через $route.params.id и находит тур через геттер getTourById.
5. Если тур не найден (неверный ID), отображается сообщение "Тур не найден" благодаря v-if/v-else.

## ️ Фильтры

В проекте используется глобальный фильтр `truncate` для форматирования текста:

```javascript
// src/filters/index.js
Vue.filter('truncate', (text, length = 400, suffix = '...') => {
  if (!text) return '';
  if (text.length <= length) return text;
  return text.substring(0, length) + suffix;
});
```

**Использование в компонентах:**
```vue
{{ tour.description | truncate(400) }}
```
